# Claim-Level Transfer — The Narrowest Remaining Gap Found So Far

**Snapshot: 21 August 2026.**

After the field, adjacent-field, transfer-validity, CBR-convergence, and last-mile scans, the broad gap claims have mostly dissolved. Current systems can retrieve cases by reasoning utility, adapt/reuse them, reject harmful sources under various criteria, learn from deployment reward, diagnose pipeline failures, revise latent state, and formally determine causal transportability under structured assumptions.

This final scan asks the narrowest question:

> **Can a learned open-domain system take one candidate source analogy and independently decide which individual projected claims are transferable, which must be vetoed, which remain uncertain, and then learn those applicability boundaries from later failures?**

The current answer from the public literature searched here is **not yet in a general foundation-model system**.

---

## 1. Candidate-level matching is real, but it is coarser than claim-level transfer

### Sen, Workiewicz & Puranam, Strategy Science 2026

**Can LLMs Aid Analogical Reasoning for Strategic Decisions? A Comparative Study**  
Canonical: https://doi.org/10.1287/stsc.2025.0426

This paper is unusually important because it distinguishes retrieval, mapping, and **matching** among several candidate analogies. Reasoning LLMs show high recall but lower precision and can construct internally coherent yet causally wrong mappings.

This establishes that candidate selection is a genuine separate bottleneck.

But the decision unit remains largely:

`which candidate analogy should I select?`

The harder target is:

`given selected source S, which candidate inferences {p1,p2,p3,...} generated by S are individually licensed in target T?`

A source can be partly useful and partly dangerous. Candidate-level precision does not by itself solve projection-level precision.

---

## 2. Transfer learning already models partial usefulness, but usually at domain/task/factor level

### Latent contextual bandit transportability

**Deng, Kyrki & Baumann, 2025** show that a causal effect conditioned on a true latent context may be directly transportable while the corresponding effect conditioned on a high-dimensional proxy is not. A VAE-based latent model and causal transport formula prevent naive negative transfer.

Canonical: https://arxiv.org/abs/2502.20153

This is an important analogue of partial validity: whether transfer is licensed depends on **which quantity / representation-conditioned effect** is being transported.

However the candidate causal effects and SCM structure are specified by the problem. The system does not generate a set of novel analogical projections and calibrate each one.

### Proxy-informed Bayesian transfer

**Sloman, Martinelli & Kaski, UAI 2025** model negative transfer when non-transferable source causes are uncertain and source differences may be unobserved. Noisy proxy information can be used to robustify transfer.

Canonical: https://proceedings.mlr.press/v286/sloman25a.html

Again, the important lesson is that hidden non-transferable factors can be treated probabilistically. The granularity is still predictive/domain transfer rather than free-form relational projection.

### Representation-based multi-source domain adaptation

**Ng et al., ICML 2025** explicitly ask what compact latent representations should be learned and transferred under multiple distribution shifts.

Canonical: https://proceedings.mlr.press/v267/ng25a.html

This shows that representation selection and selective transfer already coexist technically. The task label and prediction objective remain fixed, whereas analogy can create new target hypotheses whose transferability must be assessed one by one.

## 3. Formal analogy and causal transportability show what claim-level output could look like

Classical and modern formal accounts of analogy already distinguish mapped structure from **candidate inferences**: unmapped source propositions connected to aligned structure can be projected as hypotheses rather than treated as automatically true.

Causal transportability provides an even more operational analogue. The 2026 generalized transportability framework can return exact transport where a model-level map exists and bounded target-query answers under approximate transport.

The engineering implication is that an analogical system's output should probably not be one scalar `analogy score`. It should expose a vector over projections:

```text
source S
mapping M
projection p1: licensed, confidence 0.93
projection p2: licensed after rebinding b→y, confidence 0.81
projection p3: vetoed, mechanism mismatch
projection p4: unresolved, requires target evidence e
```

The implementation can remain latent; the evaluation unit should nevertheless be **individual projected inference**.

---

## 4. Negative applicability memory is the second half of the gap

Modern continual case-learning systems such as CASCADE can learn that some source cases have higher downstream utility than others. Failure-memory systems can retain reusable lessons. World-model agents can store mismatch-derived heuristics.

What remains difficult to find is memory at this resolution:

```text
source family S
is useful for target pattern T
for projections {p1,p2}
BUT projection p3 fails whenever relational condition X holds;
therefore retain S for future T-like cases while suppressing p3 under X.
```

A simple negative case memory might suppress the entire source and therefore destroy useful transfer. A claim-level applicability memory should reduce **false projection** while retaining valid parts of the analogy.

---

## 5. Strong falsification criterion

The claim-level gap should be considered solved only when a system can demonstrate, on heterogeneous source/target domains:

1. source and target relations are induced rather than fully predeclared;
2. one source can generate multiple candidate target projections;
3. projections are independently scored as transferable / non-transferable / uncertain;
4. calibration is evaluated per projection, not only by final task accuracy;
5. failed evidence updates the specific applicability condition responsible for the projection;
6. later targets show reduced repeated false transfer **without suppressing the source's still-valid projections**;
7. the system can change its relational representation if the failure reveals that the original mapping omitted an important distinction.

No general foundation-model system found in this August 2026 sweep satisfies all seven.

---

## 6. Benchmark implication

A useful next benchmark should deliberately make **whole-source labels insufficient**.

Each source/target pair should contain:

- several correctly aligned relations;
- multiple legitimate candidate projections;
- at least one seductive projection invalidated by a controlled target difference;
- at least one initially uncertain projection resolvable by an action/tool/observation;
- a later target that tests whether the model retained the precise negative applicability boundary.

Scoring should include:

- mapping quality;
- projection precision/recall;
- calibration / selective risk;
- causal or structural reason for veto;
- correct diagnostic action after failure;
- later reduction in repeated negative transfer.

This is the narrowest empirical target currently justified by the literature map.
